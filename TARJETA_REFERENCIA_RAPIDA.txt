PASOS EXACTOS (copy-paste):

1. Abre Google Sheets → Tools → Script editor
2. Selecciona TODO el código (Ctrl+A)
3. Copia GOOGLE_APPS_SCRIPT.gs (Ctrl+C)
4. Pega en Google Apps Script (Ctrl+V)
5. Guarda (Ctrl+S)
6. Deploy → New deployment → Web app
7. Copia el URL que aparece
8. Abre src/context/InventoryContext.jsx
9. Línea 6: Reemplaza const API_URL = "..." con tu nuevo URL
10. Prueba: Ve a SGI, agrega Categoría, verifica en Google Sheets ✅
